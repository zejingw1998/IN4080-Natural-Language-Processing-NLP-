# IN4080 – Natural Language Processing

This repository contains my obligatory assignments for **IN4080 – Natural Language Processing** at the University of Oslo (UiO).

## Course Topics

The course covers fundamental concepts and methods in Natural Language Processing (NLP), including:

- Tokenization
- Text preprocessing
- Regular expressions
- Language models
- Word and token representations
- Embeddings
- Neural networks for NLP
- Natural Language Understanding (NLU)
- Natural Language Generation (NLG)
- Machine Translation
- Text classification
- Large Language Models (LLMs)
