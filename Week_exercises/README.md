# IN4050 – Weekly Exercises

This directory contains my work on the weekly exercises for **IN4050 – Introduction to Artificial Intelligence and Machine Learning** at the University of Oslo (UiO), Autumn 2026.

The notebooks include my solutions, experiments, notes, and code written while working through the course exercises.

## Contents

### Linear Algebra

The first exercise set reviews basic linear algebra concepts used in artificial intelligence and machine learning.

Topics covered:

* Vectors and matrices
* Vector operations
* Dot products
* Linear combinations
* Matrix operations
* Geometric interpretation of vectors
* Angles between vectors
* Linear decision boundaries
* Working with **NumPy**
* Visualizing points and decision boundaries with **Matplotlib**

Files:

```text
Linear Algebra/
├── 02_practice_linear_algebra.ipynb
└── README.md
```

---

### Optimization and Search

This exercise set introduces basic search and optimization methods.

The exercises include both discrete search problems and continuous optimization.

Topics covered:

* Search spaces
* Exhaustive search
* Greedy search
* Local search
* Travelling Salesman Problem (TSP)
* Permutations
* Tour length and objective functions
* Discrete optimization
* Continuous optimization
* Loss functions
* Gradients
* Gradient descent
* Learning rates
* Visualizing optimization paths

Files:

```text
Optimization_search/
├── 02_practice_optimization_search.ipynb
└── README.md
```

---

### Supervised Learning – KNN

This exercise set introduces supervised learning and the **k-Nearest Neighbors (KNN)** algorithm.

Topics covered:

* Supervised learning
* Features and labels
* Training and test data
* Classification
* Distance measures
* Euclidean distance
* Nearest neighbors
* Choosing the value of `k`
* Prediction
* Decision boundaries
* Classification accuracy
* Model evaluation

Files:

```text
Supervised_Learning_KNN/
└── README.md
```
